Contributing
============

Thank you for your interest in contributing to the Hi3518EV300 Wi‑Fi provisioning design.

Before you start
----------------
- Read the project README and ROADMAP to align on scope and priorities.
- Open an issue to discuss larger design proposals before implementing them.

How to contribute
-----------------
- Open issues for bugs, device quirks, packaging help, or feature requests using the provided templates.
- For documentation changes, open a pull request with a clear summary of the change and why it's needed.
- Keep PRs small and focused; reference relevant issues.

Review and testing
------------------
- Document testing steps and the expected environment in PR descriptions.
- For implementation PRs (code), include sample image integration notes and a checklist for maintainers.

Code of conduct
---------------
- Be respectful. Treat community members with patience and kindness.
- If you see behavior that violates community norms, contact the maintainers.
